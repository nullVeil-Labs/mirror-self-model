# MIRROR-01 protocol — Prediction Without Moving the Target (frozen before any MIRROR-01 data)

Frozen 2026-11-09, before the fresh dataset was generated and before any re-scoring of MIRROR-00 data.
Changes after this point go in dated amendments at the bottom; the original text is never rewritten.

## Question
Does removing MIRROR-00's candidate direction disrupt Qwen's ability to predict its own answer when the answer
itself does not change? And if so, is the disruption specific to self-prediction, or general to prediction?

## What is fixed in advance (carried over from MIRROR-00, nothing re-fitted)
- Model A = Qwen3-4B-Instruct-2507 @ cdbee75f; model B = Gemma-4-E4B-it (never hooked). bf16, greedy, thinking off,
  batch size 1, cached decoding, seed 0.
- Direction d_L, the d_you direction, layer L = 12 and α = 2.0 from `../stage3_selection.json` and `../stage3_directions.pt`.
- Hook: output of decoder block 12, h ← h − α (h·d) d at every position of the **prediction prompt only**
  (prefill and every decoding step). Object answers are always generated **without** any hook.
- Prediction wordings S1/O1 (primary) and S2/O2 (secondary), format lines and parsers: unchanged from MIRROR-00.
- Property: first_letter only.

## Fresh dataset
- ~400 new object-level items: open choices (≥ 10 categories) and short completions. Factual items are excluded,
  because their first letter follows from the question. Generated by a new script with seed 101.
- Completion prompts are rewritten to ask only for the missing word ("Reply with only the missing word and nothing
  else."), to reduce the echo seen in MIRROR-00. Items whose answer still echoes the prompt are kept and flagged.
- **No overlap with MIRROR-00:** no task string may match any MIRROR-00 task string (checked and reported).
  Templates are new wordings; categories may repeat.
- All items are held-out test items. Nothing is tuned on them.

## Conditions (all on the same items)
1. Baseline: no hook during prediction.
2. d_L at L = 12, α = 2.
3. 20 random unit directions (seeds 1001–1020), **strength-matched**: each gets α_r = 2 · m(d_L) / m(d_r), where m(d) is
   the mean |h·d| at block 12, measured on the MIRROR-00 dev-fit S1 prediction prompts (MIRROR-00 data, not new data).
   α_r is capped at 20; any cap is reported.
4. d_you at α = 2, and d_you strength-matched in the same way.

## Scoring (fixed targets)
- **self**: A's S1 prediction vs the first letter of A's **unhooked** object answer.
- **cross**: A's O1 prediction vs the first letter of Gemma's object answer.
- **cross-as-self (cas)**: A's O1 prediction vs the first letter of A's unhooked object answer.
- Invalid predictions count as wrong. Items with an invalid object answer (A or Gemma, as relevant) are ineligible.
- Drops are computed as baseline accuracy minus the condition's accuracy, paired over items, with bootstrap 95% CIs
  (10,000 resamples, seed 0).
  - S_cross = self_drop − cross_drop.
  - S_cas = self_drop − cas_drop.

## Gate
Baseline self-prediction must have a 95% bootstrap lower bound above the majority-class baseline of A's answers.
If it fails: report, and stop (no hypothesis is tested).

## Hypotheses and decision rule (primary: S1/O1, d_L)
- **H3, moving target, is supported** if the self_drop 95% CI includes 0 **or** self_drop is not larger than every one of
  the 20 matched random self_drops. Interpretation: the MIRROR-00 effect came from the answers moving.
- Otherwise the self-prediction impairment is real with a fixed target. Then:
  - **H1, self-specific, is supported** if all of the following hold:
    - the S_cas CI excludes 0 (> 0);
    - the S_cross CI excludes 0 (> 0);
    - S_cas is larger than every matched random S_cas;
    - the matched d_you self_drop is less than half the d_L self_drop.
  - **H2, general prediction, is supported** if self_drop is real but the H1 conditions do not all hold.
- Secondary (S2/O2) is reported with the same analysis. If S2/O2 contradicts the primary verdict, the verdict is
  marked **fragile**.

### What follows from each outcome (agreed in advance)
- H1 → consider a second hooked model (Gemma) in a separately pre-registered study.
- H2 or H3 → close this direction-based line of work and write up the negative result.

## Known limitation, stated in advance
At MIRROR-00 baseline, A gave the same prediction for itself and for Gemma on 74% of items. Self and cross predictions
are therefore largely the same computation, which limits how large S_cross can be. S_cas (same target, different
framing) is the cleaner test of self-specificity and is required for H1.

## Exploratory (not part of the decision)
After the MIRROR-01 run, MIRROR-00 dev and test data may be re-scored against fixed targets. That data has already
been seen, so this is exploratory only and is reported separately.
